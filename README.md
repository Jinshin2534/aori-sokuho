# アオリ速報

実在のニュースから「ただ危機感を煽るだけ」の見出しを集めて、全力で煽る UI で見せるアプリ。

公開: https://aori-sokuho.vercel.app

## 何をしているか

1. Google ニュースの RSS（トップ＋「過去最悪」「警告」「懸念」などの検索）を `api/news.js` が束ねて取る
2. 見出しごとに **煽り度** を採点する（`src/lib/aori.js`）
   - 不安語（崩壊・危機・過去最悪・急増…）を重み付きで加点、【速報】や疑問形も加点
   - 「対策・相談・支援・見分け方」など、読者にできることが書いてあれば減点
   - 不安語が十分あり、できることが一つも書かれていない見出しだけを「煽るだけ」として載せる
3. 似た見出し（同じ出来事の別媒体）は文字2-gramの重なりでまとめる
4. サイレン、警告ストライプ、国民不安レベル、何の期限かわからないカウントダウン、ただ増える「悪化したニュース」数で煽る
5. 「冷静になる」を押すと、ただの見出しリストに戻り、いまできることが0件だと教えてくれる

見出しは実在のもの（出典リンク付き）。煽っているのはこのアプリの見た目だけで、記事そのものの評価ではありません。

## 開発

```bash
pnpm install
pnpm dev     # http://localhost:5800 （/api/news も同じ関数で動く）
pnpm test
```
